  docker network create --subnet 172.30.0.0/24 --gatewat 172.30.0.2 custom-subnet-net

then we can run the :

we can see detailed info of specific network with command:
    docker network inspect app-network

now we test, if two containers in the same network can be connected:
    docker run -d --name c1 --network app-network alpine sleep 3600
    docker run -d --name c2 --network app-network alpine sleep 3600

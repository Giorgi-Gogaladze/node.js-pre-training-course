3. Monitoring and Troubleshooting

<> monitoring container resource usage:

docker stats

Shows CPU, memory, network and block I/O usage.
Press Ctrl + C to stop monitoring.

<> viewing container logs with timestamps:

docker logs --timestamps task09-nginx
docker logs --timestamps task09-redis
docker logs --timestamps task09-node

<> viewing the last 20 log entries:

docker logs --tail 20 task09-nginx

<> following container logs in real time:

docker logs -f --timestamps task09-nginx

Press Ctrl + C to stop following logs.

<> inspecting container configuration:

docker inspect task09-nginx
docker inspect task09-redis
docker inspect task09-node

<> inspecting container port configuration:

docker inspect task09-nginx --format '{{json .NetworkSettings.Ports}}'

<> inspecting mounted volumes:

docker inspect task09-nginx --format '{{json .Mounts}}'

<> creating a Docker volume:

docker volume create task09-data

<> listing Docker volumes:

docker volume ls

<> inspecting the created volume:

docker volume inspect task09-data

<> running Redis with a persistent volume:

docker run -d --name task09-redis-volume -v task09-data:/data redis:7-alpine redis-server --appendonly yes

<> checking the mounted volume:

docker inspect task09-redis-volume --format '{{json .Mounts}}'

<> creating a custom Docker network:

docker network create task09-network

<> listing Docker networks:

docker network ls

<> connecting Redis to the custom network:

docker network connect task09-network task09-redis

<> connecting Nginx to the custom network:

docker network connect task09-network task09-nginx

<> inspecting the custom network:

docker network inspect task09-network

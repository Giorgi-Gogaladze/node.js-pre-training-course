but sometimes we need better management, for exmaple we dont need all contianer to have access to all the other ocntainers, so we can divide them into separate networks and if eneeded connect them(whciever we want) to 
eachother.

for that we can create  sucotm brige with command:
  docker network create app-network

that command then creates new  docker network  which i would give an IP address range and gateway:
  docker network create --subnet 172.30.0.0/24 --gatewat 172.30.0.2 custom-subnet-net
  the gateway will occupye 172.30.0.2 and the rest(3, 4, 5, 6) we can giv eth eother containers

then we can run the :
  docker network ls ___ to see network details list and we got the result:
    NETWORK ID     NAME                            DRIVER    SCOPE
    c80a95673d98   app-network                     bridge    local

we can see detailed info of specific network with command:
    docker network inspect app-network
